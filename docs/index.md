# Welcome to Rath

Rath is a tabletop RPG, a hack of Knave (by Ben Milton) that incorporates ideas from other Knave hacks with tweaking and new ideas to suit my table. Originally designed for compatibility with existing OSR material (Basic Fantasy modules, etc), it has grown into its own system while maintaining that old-school feel.

**The intent of this hack is to have a more full and robust character creation system that really makes each character feel unique.** Players can pick a class or race, some spells, and get started in moments, but there's an easy-to-use underlying system that gives players the freedom to create anything that can be imagined.

## Getting Started

New to Rath? The **[Players Handbook](Players Handbook.md)** is the whole game — core rules, character creation, and equipment. Running it? Add the **[GM Handbook](GM Handbook.md)** for tools and guidance. Those two are all you need.

### When you want more

- **[Advanced Aptitudes](Advanced Aptitudes.md)** - Expanded character abilities and options
- **[Advanced Magic](Advanced Magic.md)** - Complete magic system with 12 Circles of spells

### Other settings

The rules don't assume a genre — only the aptitude and equipment lists do. Swap those and the same system runs **[Modern](Modern.md)** or **[Science Fiction](Science Fiction.md)** games, or any mix of the three.

### Other ways to play

- **[Rath Overdrive](Rath Overdrive.md)** - Transforming Riders, built on a single Charge economy
- **[Rath Freehand](Rath Freehand.md)** - The whole game in a dozen pages. No aptitude lists, no equipment catalogue; keywords carry everything and gear is built at the table
